# 测试者确认清单

这张清单帮助不了解 Mapflow 内部术语的测试者决定是否确认模型提出的路线。它只供测试者看，不发送给被测模型。

确认最终结果前，只问五件事：

1. 我能在现实中判断它已经发生吗？
2. 每项必须结果都有具体的检查办法吗？
3. 哪些事情明确不做？
4. 哪些约束全程不能被破坏？
5. 哪些写入、发布、采购、发送或其他外部动作仍需我单独授权？

确认一个阶段前，只问三件事：

1. 它代表可观察的阶段成果，而不是一次很小的操作吗？
2. 我能拿出记录证明已经到达这里吗？
3. 它与前后阶段的区别是否清楚？

确认一段工作前，只问五件事：

1. 开始前需要什么已经成立？
2. 它独立产生什么结果？
3. 用什么实际检查证明结果？
4. 它明确不负责什么？
5. 失败时是停下、改道还是走已说明的替代路线？

出现任一情况就暂不确认：模型替你补全 unknown、把预计结果说成已经发生、相邻两段工作依赖未声明的中间产物、验收只能靠模型自评、或外部动作的授权人不清楚。直接用业务语言指出缺失项即可，无需提供节点名、边名或 CLI 命令。
