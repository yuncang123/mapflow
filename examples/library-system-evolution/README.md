# 图书管理系统演化演示

这不是一张预先生成好的最终地图。`npm run demo:evolution` 会创建一个临时 Git 工作区，并通过真实 Mapflow CLI 顺序产生：空白、两枚迷雾、现场勘探、目的地合同、反向回归候选、逐个节点/边人工确认、正式 Blueprint、路线批准、逐边授权与 Evidence、到达审计。

演示中的 `human:demo` 和检查结果都是确定性 fixture，只证明产品链路可回放，不代表真实项目已经实施或获得用户验收。

```bash
npm run demo:evolution
```

浏览器打开脚本打印的本地地址，在“地图演化镜头”中从第一帧播放。
